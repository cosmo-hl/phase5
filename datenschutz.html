Hosting

Die Webseite wird bei GitHub Pages gehostet (GitHub B.V., Amsterdam / GitHub Inc., San Francisco, USA). Beim Aufruf verarbeitet GitHub technisch notwendige Daten wie IP-Adresse, Datum und Uhrzeit sowie die aufgerufene Seite in Server-Logfiles, um die Seite auszuliefern und die Sicherheit zu gewährleisten (Art. 6 Abs. 1 lit. f DSGVO). GitHub ist nach dem EU-US Data Privacy Framework zertifiziert. Weitere Informationen: GitHub Privacy Statement.

Inhalte von anderen Webseiten

Einige Fotos werden direkt von anderen Servern geladen: Fotos der Kunsttankstelle von defacto-art.org und einzelne Mitgliederfotos von den Webseiten der jeweiligen Mitglieder. Dabei wird eure IP-Adresse an diese Server übertragen. Wir arbeiten daran, diese Fotos künftig selbst bereitzustellen.
