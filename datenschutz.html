Datenschutz

Diese Webseite verwendet keine Cookies, keine Analyse- oder Tracking-Dienste und keine Kontaktformulare. Schriften werden vom eigenen Server geladen.

Hosting

Die Webseite wird bei GitHub Pages gehostet (GitHub Inc., San Francisco, USA). Beim Aufruf verarbeitet GitHub technisch notwendige Daten wie IP-Adresse, Datum und Uhrzeit sowie die aufgerufene Seite in Server-Logfiles, um die Seite auszuliefern und ihre Sicherheit zu gewährleisten (Art. 6 Abs. 1 lit. f DSGVO). GitHub ist nach dem EU-US Data Privacy Framework zertifiziert.

Fotos von anderen Servern

Die Fotos werden derzeit direkt von den Webseiten der Fotograf:innen bzw. von defacto-art.org und dem Bilddienst Squarespace geladen. Dabei wird eure IP-Adresse an diese Server übertragen. Wir arbeiten daran, die Fotos künftig selbst bereitzustellen.
